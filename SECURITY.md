# Security Policy

## Reporting a Vulnerability

If you discover a security issue in this repository or its deployment configuration:

1. Please **do not** open a public GitHub issue with exploit details.
2. Use GitHub's private **Security Advisories** feature ("Report a vulnerability" under the repository's **Security** tab) to disclose it responsibly.
3. Include steps to reproduce and any relevant impact details.

We will acknowledge reports promptly and release a fix as soon as possible.
